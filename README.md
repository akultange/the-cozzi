# The Cozzi: first-scroll spec

A spec concept for The Cozzi homepage, made by Luka Skhiladze for the Upwork brief "Premium Single Product Ecommerce Website". It is not a live store: nothing is sold here and no data is collected.

- `index.html`: one static page. HTML and CSS are structured to become a Shopify section, with vanilla JS only for the pack selector, sticky Add to Cart and bag drawer.
- `shopify/`: the same first scroll as a Shopify Online Store 2.0 section.
- Photos are AI stand-ins, labeled on the page, framed to match the shot list in the page notes.
- Dashed underlines and outlines mark product facts only The Cozzi can supply.
